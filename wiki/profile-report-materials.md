# Profile 原报告资料公共纯读出口

> 2026-11-15，当前纯读出口已接入统一集成分支的 Health Analysis。合成验收、交接和实际服务验证状态见 [I-048](../ISSUE.md#i-048-双来源基础信息与共享profile交接)。

`health_profile.report_materials.ProfileReportMaterialsReader` 组合 `ProfileSnapshotReader` 与 `ProfileDocumentArchivePort`，不新增公开 HTTP 路由，不调用创建主体、下载、OCR、模型、解释或来源发布。调用方必须先验证用户访问范围，再调用 `read(user_id=..., subject_id=...)`；提供方始终纯读解析既有本人，显式主体须与其一致。没有本人返回空资料，不创建档案。

构造参数 `profiles`、`archives` 必须由组合根注入。`max_documents=100`、`page_size=20`、`max_restarts=1` 是本地有界执行初值，不是实测服务容量或时限承诺。文档超过配置上限明确抛 `ProfileReportMaterialsCapacityError`，不截断为完整成功；调用方负责总执行期限和资料字节上限。

返回 `materials` 按实际观测逐条提供 `id/kind/content/metadata`。原解读保留轮次、固定材料和结果引用、校验值、指针、处理质量及未核实限制；完整原 `result` 与来源贡献快照放在 `sourceSnapshot.archives`，供消费者受控追溯使用，不写普通访问日志。空观测及仅有名称、单位或参考范围的条目不制造个人临床资料，数值0、明确false、阴性和真实未知原文保留。保存资料并不表示已核验患者事实，不自动成为画像事实。

原解读与来源贡献分别判断可用性。最新原结果缺档时，仍合法的旧贡献保留自己的解释、贡献快照、材料和发布身份，不能标为缺档的新轮次。Document 公开读取新增贡献快照、捕获证明、材料引用及来源快照校验信息；消费者不解析固定引用的内部编码。仅按固定解释身份和明确观测指针消除镜像，其他来源的独立真实日期和观测位置继续保留，不按名称和值合并。

各页读取及返回前复核固定选择和来源生命周期。普通归档变化可有界重读，确认回执所绑定的本人主体或生命周期变化单独报告冲突。撤回和退休排除相应来源，跨用户数据拒绝使用。依赖读取失败与无资料分开，取消和程序错误继续传播。局部文档失效不使其余合法资料变成未核验的旧快照。画像明确性别只从公开画像事实读取；缺失、不明确、冲突、未就绪或读取失败时不分流，性别自身不产生临床资料。

生产契约和兼容展示接口继续使用原有行为。本出口的离线用例位于 `tests/unit/health_profile/test_report_materials.py`，实际 Document/Profile 组合位于 `tests/unit/bootstrap/test_profile_report_materials.py`。真实模型、MongoDB/Redis、多实例生命周期竞争及运营访问授权没有由这些离线结果代替。

## 当前 Document 材料与确认绑定

健康分析从确认回执固定本人主体和生命周期。Profile 在第一页前和返回前分别复核相同的活动主体及生命周期。经固定归档校验的完整或部分解读可先作为来源材料读取。已发布或显式退休的观察按原件文档、解释轮次和观察指针对齐。多页 Report 的正式贡献可以覆盖次页同一观察的归档表示，同值不同原件位置分别返回。未核实原文保留未知状态，不能支持个人状况。读取复用存档，不重新下载文件、调用模型或更新发布状态。

在 Chat 和 Record 中，带日期的已应用观察由 Profile 事实页提供。仍无可用日期的当前报告观察保留独立出处，可作为带明确“日期未知”的补充内容。人口学事实允许未提供起始日期，当前资料保持该值为空。生日是唯一可信年龄依据时，消费者保留出生日期值，并在 `currentAge` 单独显示年龄和计算日期。固定历史快照保存当时的取值。
