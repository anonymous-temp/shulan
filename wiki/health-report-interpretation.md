## 固定归档与响应

Document 在每轮结果完成时保存归属、原件身份、实际解析与结果引用及摘要，先于释放执行租约。固定轮次读取不会从可变文件索引改取后来结果。现有原件、完整 DocMind 响应、模型留痕、纠正和统计内容继续保留。

应用编排在持久受理后等待原文及结果归档，捕获固定快照，再以原请求 trace 分块保存最终展示响应。就绪记录仅保存响应引用、内容摘要和固定准备引用，避免把大响应内嵌单条任务记录。响应和就绪必须读回核验；写入回执丢失只在同一内容已持久存在时复用。归档或就绪失败返回实际错误。

HTTP 仍持久预留 reportId 归属与文件引用绑定，但不执行正式来源、报告历史及别名的完整交付，也不等待画像应用。Document Formal、Analysis delivery 和画像 Worker 继续通过既有生命周期恢复；提交任何可独立执行的基础命令前必须核验就绪。后台不重跑下载、OCR 或模型。仅元数据、待核实或无正文内容也保存固定响应，不制造临床来源。

同文件并发不同 reportId 按真实材料协调基础来源，并分别完成别名。后来解析不改写原执行资料或首次报告快照；旧轮次只能恢复原固定历史和别名，不能覆盖较新基础来源。详细边界见 [Analysis 固定用例](analysis-formal-source.md)。

## Document 纯读与 Profile 展示

组合根登记来源文件反查索引初始化器，运行时在 HTTP 监听及 Worker 扫描前完成索引准备；失败沿启动失败路径退出并释放资源。查询强制使用指定索引，不在读取中执行 DDL，也不在索引缺失时隐式全库扫描。

Document 的归档读取 Port 按用户、主体、文件及不透明 seek 游标有界发现固定资料，结合当前有效来源贡献与生命周期判断可读性。已有归档清单时，撤回或临时读取失败保留原固定解析 ID，生命周期另行表达；确无可证明归档时返回 extractionId=null 的文档级 unavailable，不解引用空值。历史归档缺失如实返回，不在查询中解析、发布或恢复。退休或撤回资料不能从旧观察或原始归档回退原值。

Profile 消费自己的资料读取 Port，组合根通过 Adapter 注入实际 Document 提供方。standard 保留原来源观察范围并补齐正式来源查询；complete 展开保存结果中的项目、影像叙述和待核实内容，去除兼容镜像而保留真实独立项目。没有项目的文件仍有文档级状态。组合来源按实际贡献文件筛选，不将来源主文件的其他资料带入附件查询。

完整展示不授予事实生效或核验状态。只有唯一关联的实际事实才提供其真实状态；缺日期、缺结果、未发布或未核实内容保留相应限制。同文件新归档可先于来源应用展示，不能借用旧事实核验新结果。

Profile 游标绑定 scope、文件筛选、展示选择和固定解析位置。文件跨页继续读取同一固定资料；绑定或生命周期变化返回409，参数和游标错误返回422。空项目文档也占一个分页单位，允许空页携带后续游标。公开字段与示例统一维护在 [API](../docs/api/API.md#查询原报告指标)。

## 验证边界

离线用例使用合成资料、实际模块提供方和存储替身，覆盖默认装配、持久就绪、失败与回执丢失、取消恢复、固定轮次、来源竞争、分页、归属和撤回。真实 DocMind/模型抽取质量、MongoDB/Redis 多进程与 Linux 重启仍需独立环境验收；不读取私有配置或真实健康资料进行自动验证。
