# 评估报告六章（assessment.v2）内容规格

本文是评估报告（`type=evaluate`，回调 `data.version = "assessment.v2"`）产品化的内容规格。章节结构与内容覆盖以甲方 2026-11-21 提供的示例报告（48 岁男性一例，30 页）为准；文风、判定规则和适用范围按本文执行，保证对所有用户成立。

本文是验收依据：代码、提示词、回调字段和样版渲染都按本文核对。对外字段契约仍以 [docs/api/API.md](../docs/api/API.md) 为准。

## 1. 总原则

### 1.1 分工

| 层 | 负责 | 说明 |
|---|---|---|
| 判定 | 程序 | 指标归类、状态分档、目标区间是否适用、优先级（P0/P1/P2）、计算指标、各节是否有数据。规则写成表，可单测 |
| 规划 | 模型 + 程序校验 | 选哪些主诉、组成哪些失衡集群、生活因素对应哪些集群。校验失败只影响出错的那一项，不整份作废 |
| 撰写 | 模型 + 程序校验 | 每一格的解读文字。数值、日期、分档必须与原始资料一致；引用编号必须在本报告文献表内 |
| 呈现 | 甲方前端 | 按回调里的结构化字段画图。本仓库提供样版渲染（`scripts/render_assessment_presentation.py`）作为参照 |

### 1.2 文风（所有读者可见文字）

- 正式书面语，客观陈述。不用“您”；确需指代写“受检者”，多数句子省略主语。
- 不写免责声明、推销句（如“响应敏感度极佳”）、比喻和夸张（“引擎”“全军覆没”“彻底”），不写绝对化因果（“绝非”“必然”）。
- 不出现后台与来源方用语：原件、原报告、主检、模板、模型（指生成模型时）、未形成解读、部分报告、按原件记录、问卷显示、检测方、检测机构。
- 标题用名词性短语，不用口语问句（“为什么……”改为“……的代谢与菌群线索”）。
- 参考区间取自原始检验单；目标区间只用目标表（第 3 节）中有出处的条目，并在文中给文献编号。没有出处的数字不写。
- 长段落改成“小标题 + 一段”的条目；表格单元格只放短语和数值，解释放在表下。

### 1.3 对所有用户成立

- 每一节规定“数据缺失时的写法”（下文各节“缺失时”），不留空节、不出现“暂无可展示的解读”。
- 数量随数据：主诉、集群、生活因素、文献都不固定条数。
- 性别、年龄、妊娠分流：目标区间、阈值、器官检查按适用条件选择；不适用时只显示临床参考区间。
- 优先就医提示由危险信号规则表决定，不依赖原体检报告的措辞（第 4 节）。
- 任何检查项目都必须有归属：放不进固定系统的进“其他检查”组，不丢弃。

### 1.4 状态分档（全报告统一）

| 代码 `level` | 显示 | 含义 |
|---|---|---|
| `focus` | 重点关注 | 超出临床参考区间且有临床意义，或命中危险信号规则 |
| `borderline` | 亚临床边界 | 在临床参考区间内但偏离有出处的目标区间，或轻度越界且无临床意义 |
| `normal` | 稳健达标 | 在临床参考区间内，且（如有适用目标）在目标区间内 |
| `notTested` | 未检测 | 本次资料没有该项 |

系统、集群的分档取其成员中最重的一档。

## 2. 各章内容

每节列出：内容、来源、缺失时、呈现组件与回调字段。“程序”指确定性生成，“模型”指模型撰写并经校验。

### 封面与前言

- **封面**（程序）：姓名、性别、年龄、档案编码；临床体检日期与机构；菌群采样日期（缺失时用收样日期并注明）；两次资料间隔月数与时效判断（≤6 个月为同一周期，>6 个月写明间隔、提示结论以较新资料为准）。
- **前言**（固定文字）：报告定位、双轨评价（临床参考区间与目标区间）、结构导览三条。不用“您”。
- 部分成功时不在正文显示“部分报告”提示；完整性由回调的 `status` 与 `partialReasons` 表达。

### 第一章 全息健康图景概览

**1.1 基础体格与人体成分深度校准**
- 内容：身高、体重、BMI、腰围、腰臀比、体脂率、脂肪量、内脏脂肪面积、骨骼肌量、基础代谢率、细胞外水比、血压、心率。一句体型判断（如“中心性肥胖伴内脏脂肪蓄积、骨骼肌量正常”），由程序给出判定要素、模型成句。
- 缺失时：没有人体成分只写身高体重腰围血压；完全没有体格资料写“本次资料未包含体格测量”。
- 组件：每项一条参考范围条（实测点、临床参考带、目标带）。字段见 2.7。

**1.2 多系统健康状态分级总览**
- 五个固定系统：糖脂代谢与心脑血管；肝胆胰消化与肾脏代谢；肠道微生态与黏膜屏障；内分泌激素与骨骼肌肉；血液免疫、甲基化与氧化应激。另有不属于上述系统的异常（乳腺、妇科、肺、感染、自身免疫等）时追加第六项“其他器官与专项检查”。
- 每个系统：分档（程序）、关键异常锚点（程序，最多 6 项，其余计数）、一句定论（模型）。
- 缺失时：无数据的系统显示“未检测”，不写定论。

**1.3 临床优先排查项与未检风险提示**（三部分，程序决定条目，模型成句）
1. 优先排查（P0）：由危险信号规则（第 4 节）命中，给出时限、科室、需完成的检查。没有命中时写“本次未发现需优先就医排查的结果”。
2. 常规专科随访：结节、息肉、囊肿等需定期复查的发现与原检查建议的间隔。
3. 检测盲区：由“发现 → 建议补查项目”规则表给出、本次未做的项目及理由。没有时省略该部分。
- 组件：行动卡片（事项、时限、科室、依据）。字段：`priority`、`timeframe{text, days}`、`department`、`basisRows`。

**1.4 核心系统失衡态势速览**
- 内容：失衡集群清单（编号、短名、优先级）与一句总述；中心标签由程序取关键指标（如 BMI、内脏脂肪、菌群总分分级）。
- 数量随数据（1–6 个）。全部正常时写“本次各系统未形成需集中干预的失衡方向”，不画图。
- 组件：关系图（中心 → 集群）。

### 第二章 核心主诉表型与多维客观指标关联解析

**2.1 主诉症状谱与临床检验信号印证**
- 内容：每条主诉一行（S1、S2……）：表现、持续时间与加重情境（取自问卷与自述）、相关临床信号、相关菌群与代谢证据。
- 缺失时：未记录主诉写“本次未记录主诉症状”，2.2 改写为“主要异常与日常感受的关联”只就已检出的异常说明可能的日常表现，不虚构症状。
- 组件：主诉 × 证据矩阵，单元格只放带数值的标签。

**2.2 躯体感知背后的微生态与代谢线索**
- 每条主诉一个条目：名词性标题 + 解析（指标、菌群、生活因素如何共同解释该表现，带数值与文献编号）。
- 末尾一段“综合印证”：把主诉、异常和生活因素串成一条链。不写疗效预期与推销句。

### 第三章 分系统临床检验与亚临床功能双轨评估

**3.1–3.5 分系统表**
- 3.1 糖脂代谢、胰岛素敏感性与心血管系统；3.2 肝胆胰消化、肾脏代谢与营养辅酶；3.3 血液学、铁代谢、免疫与一碳甲基化（感染与免疫学指标归此）；3.4 内分泌激素、骨骼肌肉与器官影像（甲状腺、乳腺、妇科、肺、骨密度、脊柱、眼、口腔等任何器官的影像与查体归此）；3.5 专项检测与筛查（动脉硬化、脑血管功能、糖尿病风险筛查等设备检测，肿瘤标志物异常，其他未归类项目放本节末“其他检查”）。
- 每行：项目、实测结果、临床参考区间（目标区间及文献编号）、状态（双轨：临床状态 + 目标状态，合成 `level`）、解读（模型，带数值）。
- 原始资料文字与数值互相矛盾时（程序检出），在表下加“数据校准说明”，写明以哪个为准及理由。
- 缺失时：整组无数据则不出现该小节标题，在章首说明本次未包含的检查类别。

**3.6 历年指标演变趋势与已确认稳健安全基线**
- 趋势：同一指标有两次及以上结果时列出（日期、数值、方向）。没有时写“本次资料未包含可比较的历次结果”。
- 稳健基线：正常的肿瘤标志物、核心器官功能（肝、肾、心、血常规）汇总一段。
- 组件：小折线图；基线用清单。

### 第四章 肠道微生态宏基因组与消化微环境深度评估

- **章首说明**：采样情况（采样前抗生素、泻药、益生菌使用，取自问卷；未记录时写“采样前用药情况未记录”）、发酵耐受判断（产甲烷菌、产气症状、排便性状）。
- **4.1 消化道器质基础与消化液微环境**：口腔与上消化道（口腔查体、幽门螺杆菌、胃病史）、肝胆胰（胆囊、肝脏、淀粉酶、胆汁酸）、下消化道黏膜（隐血、粪常规、排便症状）。
- **4.2 微生态宏观稳态指数与肠道生物学年龄**：总分与分级、多样性、检出种数、GMWI2、肠龄与实际年龄差、F/B、肠型、屏障/抗炎/免疫分、B/E 比值。组件：刻度条（报告给出的分级区间作底色）。
- **4.3 核心功能菌群结构、条件致病谱与毒力因子**：有益菌、产短链脂肪酸菌、高丰度偏移菌、细菌性致病菌与条件致病菌、真菌病毒寄生虫、毒力与耐药基因。每类：异常项（方向、丰度、参考范围）、正常项计数与示例、功能意义。组件：异常菌丰度对参考范围的偏离条；正常菌只计数。
- **4.4 菌群营养合成与外源毒素代谢潜能**：按报告中的通路组（数量按实际，不写死“十维”）列出 0–100 分子项、分档区间（取自报告说明，如 0–25 偏低、25–75 正常、75–100 偏高）、与临床指标的交叉印证。组件：评分条带分档底色。
- **本章风险小结**：菌群疾病风险模型的分值与阈值；明确写出“健康管理以临床检查结果为准”。

### 第五章 系统失衡集群综合评估与生活诱因溯源

**5.1 个体化系统失衡集群定性与健康影响解读**
- 每个集群：编号、名称、优先级（P0 优先医疗排查 / P1 核心干预 / P2 协同调理）、证据链（临床与影像锚点、微生态与代谢锚点、相关生活因素）、健康影响解读（模型）、处理方向（模型或原检查建议）。
- P0 只由危险信号规则授予；P1、P2 由规划给出、程序校验。
- 全部正常时写“未形成需集中干预的失衡集群”，列出维持要点。

**5.2 ATM 健康诱因全景复盘与健康认知校准**
- 先天背景与触发事件：家族史、既往病、用药、手术、烟酒史。
- 日常维持诱因表：饮食与进餐、饮酒与饮品、睡眠、运动与久坐、精神压力与口腔护理五个维度；每维度：行为特征（取自问卷）、相关异常、关联集群编号。未记录的维度写“未记录”。
- 健康认知校准：只在问卷或自述中有可对照的认识时写（2–3 条），否则省略。

### 第六章 综合健康评估结论与精准干预方向建议

**6.1 核心健康风险分层总结**（三层固定，内容随集群）
1. 第一层级：临床专科排查与随访（首月）——P0 集群、常规随访、检测盲区。
2. 第二层级：核心代谢与肠道微生态干预（90 天）——P1 集群。
3. 第三层级：营养储备与长期健康维护（持续）——P2 集群与维持要点。
- 某层没有事项时写一句说明，不留空。

**6.2 全周期微生态与生活方式协同管理方向**
- MTPN 个性化功能靶向配方：功效菌选择依据（缺失或偏低的菌）、益生元与膳食纤维（按发酵耐受与排便性状）、营养素配方方向（按营养合成偏低与临床指标）。只写方向，不写产品名和剂量。
- LSMI 去诱因个性化生活方式干预：按 5.2 的诱因维度给出要点。
- 有 P0 事项时写明“先完成第一层级排查再开始配方干预”。
- 报告末尾不加免责声明。

### 2.7 结构化字段（供前端画图）

在现有字段之外追加，不改名、不删除。所有新字段可为 `null`。

| 对象 | 追加字段 | 说明 |
|---|---|---|
| 检测行 | `valueNumber`、`referenceLow`、`referenceHigh`、`referenceKind`（`range`/`upper`/`lower`/`qualitative`）、`level`、`direction`（`up`/`down`/`null`） | 由程序从原文解析；解析不了为 `null` |
| 检测行 | `target{low, high, text, evidenceRefs}` | 只在目标表条目适用时给出 |
| 菌群评分行 | `score`、`bands[{label, low, high}]` | 分档区间取自报告说明 |
| 菌群丰度行 | `abundance`、`referenceLow`、`referenceHigh` | 百分比数值 |
| 系统、集群 | `level`、`anchors[{name, value, unit, direction}]`、`moreCount` | |
| 优先事项 | `priority`、`timeframe{text, days}`、`department` | |
| 趋势 | `points[{date, value}]` | 已有 |

## 3. 目标区间表（双轨中的“目标”）

- 位置：`modules/report/assessment_targets.json`（替代只取自示例的 `assessment_template_01_comparisons.json`）。
- 每条：指标、别名、单位与换算、目标区间、适用条件（性别、年龄段、非妊娠、排除的既往病，如冠心病、糖尿病、甲状腺术后）、依据说明、出处（指南或文献：标题、年份、DOI/URL）、证据等级。
- 生成方式：由 `scripts/build_assessment_targets.py` 调用模型、DeepSeek 联网检索、文献库与 PubMed 生成候选，程序核对出处页面确实包含该数值后入表；无出处的候选不入表。表随代码版本发布，运行时不再临时检索。
- 运行时：只对适用的受检者显示；不适用或没有条目时，只显示临床参考区间。

## 4. 危险信号规则（P0 与 1.3）

- 位置：`modules/report/assessment_red_flags.py`，规则是数据表，每条：触发条件（指标与阈值、定性结果、影像分级）、时限、科室、建议检查、出处。
- 至少覆盖：粪便隐血阳性；肿瘤标志物明显升高；BI-RADS 4 类及以上、TI-RADS 4 类及以上、Lung-RADS 3 类及以上或肺结节需随访；血红蛋白明显降低；血钾、血钠、血糖、肌酐、转氨酶等危急或明显异常；心电图严重异常；尿蛋白、尿潜血阳性伴肾功能异常等。
- 原检查建议含“尽快/及时就诊”时也授予 P0（作为补充，不是唯一依据）。

## 5. 验收

- 多画像样例集（不少于 8 例）：48 岁男性实例；62 岁女性多病；29 岁男性基本正常；无问卷；只有菌群；体检全部正常；含危险信号；另一家医院的指标写法与育龄女性；70 岁以上多病。
- 每例自动检查：六章各节非空或有缺失说明；异常项全部出现在报告中；禁用词为 0；数值能回溯到原始资料；P0 与危险信号一致；耗时不超过 30 分钟（目标 20 分钟）。
- 48 岁男性实例另与甲方示例对照：示例中出现的事实，本报告覆盖的比例。
