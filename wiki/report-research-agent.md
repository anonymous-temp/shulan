# Report 有界研究子智能体

本文说明本地重构实现；新研究路径默认关闭，尚未进行真实模型质量评测、Mongo 并发和外部回调联调，不代表已启用或上线。

## 调用边界

HTTP 查询继续直接访问 Report 数据服务。现有 Report 主任务先执行既有提取、检索和公共证据补查，仍有未覆盖问题时才在明确配置后调用私有 `ResearchAgent`。父任务固定问题、身份、版本与截止时间；子任务使用 AION 0.6.0 原生工具循环执行“检索、观察、改写查询、再检索、返回引用或缺口”。没有全局主控，也不增加其他域的模型调用。

`knowledge_search@knowledge-search-v1` 通过公共 KnowledgeGateway 读取文献摘要和指南原文。检索结果不能修改目标、权限或输出协议。AI 摘要不会被当成原文；超过单项 12 KB 的原文整项排除，不截断或改写为摘要。每轮最多读取五项，每个研究单元最多八次模型和八次工具调用，生产默认每次研究最多四个问题。未研究的问题仍返回缺口。

研究结果只包含通过引用与来源校验的候选证据，重新经过 Report 原有候选筛选、原文引用及结论审查。内部草稿、推理、工具文本没有业务 SSE 出口，也不会直接写入报告正文。最终正文沿原有保存及交付流程处理。

## 版本、预算和持久化

Report 受理清单包含研究选择、Prompt 摘要、模型配置与实际提供商/模型、工具版本、预算和评测记录。配置不同的 Worker 不会隐式运行旧任务；需保留对应旧 Worker 或按既有中断策略封口。关闭研究配置不代表重跑已完成报告。

研究 journal 使用 Report 批次集合名加 `_research` 后缀，固定用户、会话、报告、目标、清单和首个截止时间，并在工具返回模型前持久保存实际查询及原始材料。重复工具调用 ID 只允许同内容重放。通用 `agent_tool_runs` 账本保存父子执行、用量、权限、取消及回执，使用多数写入确认。无需跨集合事务；journal 已写而账本未受理时，可重试固定输入，当前父期限更短则拒绝继续；无法确认执行结果时不重新执行原生循环。

这里的父预算仅覆盖 Report 委派的研究步骤，不能代表整个既有报告生成过程的模型总预算。模型/工具调用数和截止时间是硬限制；Token 用量是全轮统计，不承诺精确费用上限。每个研究单元只有完成回执重放，不具备逐步 checkpoint 续跑。进程中断、取消和预算耗尽返回部分完成或缺口；回调补投不受研究预算影响。

## 配置与启用

仅维护 `.env.example*` 模板；真实配置由维护者设置。默认 `SHULAN_REPORT_RESEARCH_ENABLED=false`，三个预算为 `0`。开启时必须填写明确的模型、经审核的评测记录和预算，否则拒绝构造研究执行能力。

显式开启但预算、模型或 Knowledge 依赖无效时，生产适配器返回带原因类型的 `UnavailableResearchAgent`，不会伪装为关闭，也不关闭共享资源或中断其他模块装配。Report 主 Agent 在注册和每次执行前核验研究依赖；不可用时只将 `report-main` 标为未就绪，并让依赖 AI 用例明确失败。普通 Report 查询及其他域仍可启动。研究能力或固定模型身份失效不会被可选补查的普通异常降级吞掉；临时检索失败仍保留原候选和既有降级语义。有效配置的既有执行清单不增加字段，默认关闭路径仍不创建资源或读取运行器依赖。

| 配置 | 要求 |
|---|---|
| `SHULAN_REPORT_RESEARCH_ENABLED` | 默认 `false` |
| `SHULAN_REPORT_RESEARCH_MAX_MODEL_CALLS` | 开启时 2—8 |
| `SHULAN_REPORT_RESEARCH_MAX_TOOL_CALLS` | 开启时 1—8 |
| `SHULAN_REPORT_RESEARCH_TIMEOUT_SECONDS` | 开启时 1—120 秒，并受父任务剩余时间限制 |
| `SHULAN_REPORT_RESEARCH_MODEL` | 显式模型名称；实际派发前再次核对 |
| `SHULAN_REPORT_RESEARCH_EVALUATION_REFERENCE` | 经审核的评测记录标识，填写标识不替代评测 |

DeepSeek 内置搜索与工具模式分离；本研究模式关闭提供商内置搜索。平台继续使用已锁定 AION 0.6.0，不要求上游升级。工具参数使用它支持的 Schema 子集，长度约束由执行器补充验证。

## 验证与发布门槛

离线回归通过真实 AION SDK 加 MockTransport 覆盖空结果后补查、父子累计用量、默认关闭、虚构/越界引用拒绝、来源原文、预算耗尽、取消、版本与模型漂移、持久重放及候选返回父任务。Mongo adapter 使用合成集合验证固定输入、幂等和写入确认；这些都不是生产数据库并发验证。

启用前需对固定病例集比较原路径与新路径：问题覆盖率、原文适用性与引用正确率、错误与缺口率、模型/工具次数、Token、费用和耗时；检查医疗结论不得超出证据，并由领域负责人确认收益与阈值。真实质量、并发、回调联调和灰度验收仍独立记录。关闭配置和按任务版本保留旧 Worker 是回退路径，不能重新生成已完成产物。
