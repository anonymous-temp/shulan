
    # 任务指令 (Task Definition)
    请根据下方提供的肠道菌群评估报告数据，识别所有具有临床意义的异常或高风险情况。
    对于每一个发现的异常问题，请严格按照要求提取并输出其指标依据、病理机制、干预建议、优先级、小提示及循证证据。

    # 分析与生成逻辑 (Workflow)

    1. 核心异常证据链 (abnormal_findings)：对提取出的每一个病理异常维度，务必提供以下内容：
       【强制兜底指令】：如果输入数据中未能识别出明显的异常指标，或者数据量极少无法判定异常，**绝对不要返回空的 abnormal_findings 数组！** 必须生成至少 1 条“基础状态”条目：将 `problem` 定为 "未见明显高危异常" 或 "微生态日常维持"，`priority` 定为 "长期主线"，`indicators` 可留空或填入现有指标，并在机制与建议中给出基础的临床肠道保养建议。
       - `problem` (异常问题的严谨循证命名)：字数必须严格限制在12个字以内！例如“肠道轻度炎症风险升高”、“短链脂肪酸合成不足”。
       - `priority` (干预优先级)：评估该问题的严重程度，从以下三个选项中选择一个：`"优先处理"`、`"观察"`、`"长期主线"`。
       - `indicators` (实际异常数据)：只列出**支撑该异常结论的实际异常数据**，绝不罗列正常指标！必须包含 `name`（指标名/菌种拉丁名）、`value`（检测值）、`status`（偏高/偏低/阳性/严重超出正常范围）。
       - `biological_mechanism` (生理病理机制)：语言需通俗易懂，直接向患者解释上述指标背后的生理或病理机制，说明其如何引发身体不适或未来健康风险，必须开门见山直接陈述核心机制！绝对禁止使用“受检者当前评估未见……”、“本次评估未捕获到具备明确临床意义……”、“根据检测数据……”等描述评估状态的冗余废话。
       - `recommendations` (临床上怎么处理)：针对当前的异常问题 (problem)，给出具体、可执行的临床上医学与微生态干预方案。
         - 格式红线：直接输出干预内容，绝对禁止输出类似“生活层面：”、“微生态调节：”、“饮食建议：”等分类标签前缀。
         - 内容红线：禁止提供宽泛的生活方式干预（如早睡早起、规律作息、缓解压力、多运动等）。必须完全聚焦于临床维度的微生态干预（如补充特定功效的益生菌菌株/益生元）、医学营养治疗或对症的肠道健康管理方案。
       - `tips` (小提示)：必须基于当前的异常问题 (problem) 来提供。包含 `special_reminder`（针对该异常的特别提醒，如必须规避的特定恶习或就医指征）。       
       - `evidence_refs` (参考文献 ID)：支持这一依据的参考文献 ID 列表（从输入数据中匹配提取）。
       - `evidence_level` (证据强度)：根据关联文献及临床共识，评估该证据链的强度，严格使用以下标准表述之一：
         - `"强（大规模临床/RCT/前瞻性队列研究证实）"`
         - `"中（多中心临床观察/高水平统计相关性）"`
         - `"弱（基础实验/体外或动物模型提示）"`

    2. 全局参考文献集合 (evidence_refs)：提取当前整个模块涉及的去重后的 `evidence_refs` ID 数组。

    # 输出格式 (Output Format)
    严格限制：绝对不要输出任何前言、解释性文字或总结。禁止使用任何 Markdown 标记（不要输出 ```json 或 ``` 包裹符），确保你的回复直接以 `{` 开始，以 `}` 结束。
    【缺失兜底规则】：对于要求动态提取的键，若无数据请直接省略该键值对；对于 Schema 中的固定必填字段，若缺乏数据支撑无法生成，请直接输出空字符串 "" 或空数组 []，绝对禁止输出“缺失”、“无数据”等词汇！
