# 任务指令
你正在编写《用户报告解读参考手册》的**第一部分：健康综合评估（全局速览）**。
目标：让解读人用 3 到 5 分钟带用户看懂全局，建立信任，且不让用户产生恐慌。

# 输入数据
【受检者与报告信息】
${meta_json}

【第一部分素材】
${part_json}

素材字段说明：
- `overview`：报告 1.1 健康总览的正文结论。
- `assessment`：综合评分 `score`、等级 `level_label`、六维 `dimensions`（每维含分数、等级、一句话解释、关联疾病与风险等级），以及程序已算好的最短板维度 `lowest_dimension` 与优势维度 `highest_dimension`。
- `priority_items`：报告 1.2 需要优先关注的事项，含问题名、优先级与行动建议。
- `top_three`：需要优先关注的三件事（按优先级排好序，直接用，不要自己重排）。
- `grading_list`：报告 1.4 问题分级清单，含级别、问题与一句话说明。
- `indicator_rows` / `imaging_rows`：报告 1.3 的异常指标表与影像检查表。
- `microbe_overview`：菌群结果的汇总口径（共几项、几项超标、几项缺乏）与 2.6 节整体说明。
- `data_gaps`：本次资料的缺口说明，保留在 `cautions` 或 `faq`；影响结论理解时，照读话术也需简短说明限制。

# 本部分的讲解要求

1. **讲解顺序**：先讲实际存在的综合评分与结论，再讲已有优先事项及分级依据；缺少评分或事项时不推定正常，不凑足三件事。
2. **分级讲法**：先讲级别最高的那条，再讲其余行动重点；逐项沿用报告的行动建议，不由级别自行推断就医必要性或复查间隔。
3. **分级表类比**：可用交通信号灯说明关注顺序；具体行动与时间必须来自 `grading_list`，不自行添加“立即”“本月”或“定期复查即可”。
4. **六维讲法**：先指最短的那根轴（`lowest_dimension`），说明它为什么最需要关注，再指优势维度（`highest_dimension`），先抑后扬。每个维度的说法必须来自该维度的 `explanation`，不要自己发挥。
5. **关联疾病讲法**：`related_diseases` 是菌群模型评估出的风险倾向，讲到时必须带"不等于疾病诊断"的声明。
6. **菌群表讲法**：只讲 `microbe_overview` 的汇总口径（几项超标、几项缺乏），绝对不要逐条念菌名。
7. **严禁**：不得逐条念 `indicator_rows` 里的异常指标（用户会看到满页"异常"而恐慌，挑最关键的一到两项讲即可）；不得在本部分展开任何机制细节，机制留到第二部分。

# 字数与条数约束
- `key_points`：3 到 5 条，每条不超过 40 字。
- `script.body`：2 到 5 段，每段不超过 120 字。
- `visual_guide`：2 到 4 条。
- `faq`：5 到 8 条，每条 `answer` 不超过 120 字。
- `cautions` 三个列表各 1 到 3 条。

# 输出格式
请严格遵守以下 JSON Schema（`kind` 字段照抄，不要改动）：
{
  "part_no": 1,
  "title": "第一部分 健康综合评估",
  "key_points": [
    {"text": "本节解读人必须讲到的一句话要点", "anchor": "1.1"}
  ],
  "script": {
    "kind": "script",
    "opening": "本节开场的一句话，衔接上文",
    "body": ["第一段照读话术", "第二段照读话术"],
    "closing": "本节小结并转场到第二部分的一句话"
  },
  "visual_guide": [
    {
      "anchor": "1.1",
      "target": "radar",
      "order": ["先指哪里", "再指哪里"],
      "talk": "指着图说的照读话术"
    }
  ],
  "faq": [
    {
      "question": "用户可能怎么问",
      "answer": "照读的应答话术",
      "source": "依据出处，如：报告 1.1 健康总览"
    }
  ],
  "cautions": {
    "must_say": ["本节必须讲到的点"],
    "easy_wrong": ["容易讲错的点"],
    "forbidden": ["绝对不能说的话"]
  }
}

`target` 只能取以下四个值之一：
- `radar`：六维雷达图（anchor 用 "1.1"）
- `score`：综合评分环（anchor 用 "1.1"）
- `table`：表格（1.3 三张表、1.4 分级清单）
- `text`：纯文字段落，指着带读
