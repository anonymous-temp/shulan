
    # 任务指令 (Task Definition)
    作为肠道微生态健康管理专家，请根据受检者的评估报告数据与已确定的干预组合，为其生成**精简版**的饮食处方、运动处方和行为处方，用于临床医嘱报告中的“生活方式处方”卡片。

    # 输入数据 (Input Data)
    受检者的评估报告数据：${evaluate_json}
    已确定的干预组合：${recommend_method}

    # 任务需求 (Workflow)
    三个处方结构完全一致，均由“一句话总述 summary”和“2-3 条要点 points”组成：

    1. 饮食处方 (diet)
       - summary：一句话说明推荐的饮食模式与方向（如：以地中海饮食为基础，多蔬果全谷、少油少糖）。
         信息不明确或命中代谢综合征/脂肪肝/血脂异常时，默认以地中海饮食为基础。
       - points：从“餐盘比例、膳食纤维、需减少的食物”中挑最关键的 2-3 条。
         餐盘比例只能用视觉化量词（如：每餐约1/2蔬菜+1/4蛋白+1/4主食），禁止使用克、毫升等绝对计量单位。

    2. 运动处方 (exercise)
       - summary：一句话说明运动方式与强度方向（如：以中等强度有氧为主，配合规律抗阻训练）。
       - points：从“有氧运动频率/时长/方式、抗阻训练频率、餐后活动”中挑 2-3 条，写清频次或时长。
         存在超重、关节问题或心血管风险时，优先推荐游泳、骑行等低冲击方式，并适当降低强度。

    3. 行为处方 (behavior)
       - summary：一句话说明作息与生活习惯的管理方向（如：规律作息、戒烟限酒，坚持症状记录）。
       - points：从“睡眠与午睡、烟酒管理、用药管理（避免自行滥用抗生素等）、排便/腹胀/饮食记录”中挑 2-3 条。
         干预组合包含“健康人源肠道菌群移植胶囊(PFMT)”时，必须有一条写明疗程内禁酒、非医嘱不自行使用抗生素。

    # 篇幅与风格（严格执行）
    - summary 每条不超过 30 个汉字；points 每条不超过 20 个汉字，最多 3 条。
    - 只写可执行的具体做法，不写机制解释、不写原因分析、不写免责话术。
    - 用语通俗、简洁，面向受检者本人阅读。

    # 输出格式 (Output Format)
    严格限制：绝对不要输出任何前言、解释性文字或总结。禁止使用任何 Markdown 标记（不要输出 ```json 或 ``` 包裹符），确保你的回复直接以 `{` 开始，以 `}` 结束。
    请严格遵守以下 JSON Schema（示例内容仅供参考格式，不可照抄）：
    {
        "diet": {
            "summary": "以地中海饮食为基础，多蔬果全谷，少油少糖少盐。",
            "points": ["每餐约1/2蔬菜+1/4蛋白+1/4主食", "膳食纤维逐步增至25-30g/日", "少吃油炸、加工肉和含糖饮料"]
        },
        "exercise": {
            "summary": "以中等强度有氧为主，配合规律抗阻训练。",
            "points": ["每周5次快走或骑行，每次30分钟", "每周2-3次力量训练", "餐后轻快步行10-20分钟"]
        },
        "behavior": {
            "summary": "规律作息、戒烟限酒，坚持记录身体变化。",
            "points": ["23点前入睡，每晚睡足7-8小时", "戒烟限酒，不自行服用抗生素", "记录三餐、腹胀与排便情况"]
        }
    }
