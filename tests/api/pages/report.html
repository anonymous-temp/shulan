开发用模拟回调

使用 python -m tests.api.serve_pages 启动页面服务，即可通过此地址接收回调并返回 HTTP 200；纯静态托管不提供此接口。后端配置此地址并重启后，对新受理的报告生效。

地址必须能从后端访问，localhost 指后端所在机器或容器。已受理批次保留原回调地址；修改配置并重启后，可执行 python -m scripts.report_callbacks migrate-pending 将积压任务整体切换到当前配置地址。
