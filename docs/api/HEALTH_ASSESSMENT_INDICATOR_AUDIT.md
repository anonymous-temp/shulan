# 健康管理评估指数指标映射审计

## 当前规则边界

当前 `ruleVersion` 为 `2.0.0`。公开图表从精神、免疫、肿瘤、泌尿、神经、心脑血管、消化、代谢八个候选系统中动态选择六个。原 1.0 的指标评分仅作为新系统维度的底层确定性计分组件。

预览页的展示去重规则为：

- `explanation` 只说明该维度的健康含义，不重复指标数值。
- `evidenceUsed` 是参考指标的唯一完整展示位置。
- `ruleBasis` 按规则来源和版本分组，相同来源只显示一次，组内保留各指标边界。
- 异常指标的数值、参考范围和临床意义只在“异常指标”模块完整展示。

## 当前八维映射

| 候选维度 | 主要信号 | 计分边界 |
| :--- | :--- | :--- |
| 精神系统 | 精神心理相关疾病风险 | 高风险 45、中风险 65、低风险 80；待评估不计分 |
| 免疫系统 | 免疫及自身免疫相关疾病风险 | 同上 |
| 肿瘤 | 肿瘤相关风险 | 同上 |
| 泌尿系统 | 肾功能、尿酸及泌尿相关疾病 | 指标组件与疾病风险取更需关注者 |
| 神经系统 | 神经系统相关疾病风险 | 高风险 45、中风险 65、低风险 80；待评估不计分 |
| 心脑血管系统 | 血压、血脂、吸烟及心脑血管疾病 | 指标组件与疾病风险取更需关注者 |
| 消化系统 | 肠道微生态、肠道屏障及消化系统疾病 | 两个指标组件均值与疾病风险取更需关注者 |
| 代谢系统 | 糖脂代谢、体重体成分及代谢疾病 | 两个指标组件均值与疾病风险取更需关注者 |

一个疾病只在主归属系统扣分；次级归属只做解释，不重复计分。当匹配维度不足六个时，按心脑血管、代谢、消化、免疫、泌尿、神经的稳定顺序补位；证据不足的补位维度显示“暂不评分”。

## 底层指标组件映射

| 维度 | 主要计分输入 | 辅助或派生输入 | 当前权重结构 |
| :--- | :--- | :--- | :--- |
| 肠道微生态 | 肠道总评分、GMHI/GMWI2、多样性、菌种数、B/E 比值 | 菌群组成、致病潜能、膳食纤维需求、生物膜和氧化应激相关指标 | 肠道总评分可直接映射；否则按整体 60% + 组成 40% |
| 肠道屏障 | 屏障功能、抗炎/免疫能力或黏膜炎症核心指标 | 短链脂肪酸及其他屏障辅助指标 | 核心 70% + 辅助 30% |
| 糖脂代谢 | 空腹血糖、HbA1c、OGTT 2 小时血糖 | LDL-C、非 HDL-C、甘油三酯、总胆固醇、HDL-C | 糖代谢 50% + 脂代谢 50% |
| 心血管风险 | 收缩压、舒张压 | LDL-C、非 HDL-C、吸烟状态、已确认糖尿病或心血管疾病背景 | 血压 45% + 危险背景 55% |
| 体重与体成分 | 由身高和体重计算的 BMI | 腰围、体脂率、内脏脂肪、骨骼肌量 | BMI 50% + 体成分 50% |
| 肾脏与尿酸 | eGFR 或根据血肌酐、年龄和性别派生的 eGFR；UACR | 血尿酸 | 肾功能 60% + 尿酸 40% |

## 跨维度重复输入

| 指标或病史 | 当前参与维度 | 当前风险 | 建议的下一步 |
| :--- | :--- | :--- | :--- |
| LDL-C、非 HDL-C | 糖脂代谢、心血管风险 | 同一血脂信号可同时影响两个维度，综合分中存在重复贡献 | 由医学负责人确认是否将其设为“糖脂代谢主计分、心血管风险辅助解释” |
| 糖尿病背景 | 糖脂代谢的封顶/诊断背景、心血管风险背景 | 既可影响维度封顶，也可进入风险背景 | 区分“主计分”“分数封顶”和“辅助解释”三类作用 |
| BMI 与心血管代谢含义 | 体重与体成分直接计分；可在其他维度的健康解释中被引用 | 如果未来将 BMI 再加入其他计分，会产生新的重复贡献 | 维持当前“体成分主计分、其他维度仅解释”边界 |

## 计算规则后续变更条件

任何跨维度计分去重都会改变最终分数，不应在本次展示改造中静默实施。实施前需要：

1. 由医学负责人确认每个重复指标的主评分维度和辅助解释维度。
2. 用历史报告生成新旧分数对照，审查分布及异常跳变。
3. 同步修改规则文档、单元测试和回调示例。
4. 将 `ruleVersion` 升级为新的语义版本后再发布。
