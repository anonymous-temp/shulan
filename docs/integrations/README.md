# 外部依赖接口文档

> **Status**：内部集成参考
>
> **Last Updated**：2026年8月20日

本目录存放 Shulan 依赖的第三方或公司内独立服务的原始接口资料，用于开发、联调、运维和故障排查。目录中的原始资料不是聚合契约本身；如果某项能力属于 Shulan 对外 API，即使由其他独立服务直接提供，其完整公开字段和调用约定仍应保留在 `docs/api/API.md`。

## EviMed

| 文档 | 用途 | 项目接入位置 |
|---|---|---|
| [知识库检索 API](./evimed/知识库检索API.md) | 文献、指南、说明书和临床试验检索 | 后端依赖：`agents/knowledge/`、`report_api/clients.py` |
| [语音与文档解析 API](./evimed/语音与文档解析API.md) | 独立语音识别和文档文本提取服务 | Shulan 对外 API 的组成部分；聚合契约见 `docs/api/API.md` |

## 维护边界

1. 原始依赖文档按供应商或独立系统分组；新增依赖时使用 `docs/integrations/<provider>/`。
2. 已接收的原始文档保持原文，不在正文中增加项目判断；目录定位、适配位置和时效说明写在本导航页或相关架构文档中。
3. 对外 API 是否由 `server.py` 承载不是唯一判定条件。由公司其他项目直接提供、但纳入 Shulan 产品接口范围的能力，也必须完整写入 `docs/api/API.md`。
4. 原始资料与当前聚合契约不一致时，先核对实际服务和责任边界，再分别更新上游资料来源与 `API.md`，不得直接删除已对外提供的能力。
5. 文档不得包含生产密钥或真实用户数据；已发布的 `docs/api/history/` 不因目录重分类而追改。
