# 树兰\-灵犀接口文档（11 月份）

## 健康分析生成接口\(灵犀提供\)

### 入参

```JSON
{
  "userId": "",  // 用户 ID
  "name": "张三",
  "age": 30,
  "gender": "男" | "女",
  "groupId": "", // im 群组 id，用于后续获取聊天记录
  "surveyList": [ // 问卷列表
    {
       "schema": SurveySchema // 问卷schema 定义见附件,
       "answer": {} // 问卷提交答案，结构见附件
    },
    ...
  ]
}
```

### 预期返回

```JSON
{
   "healthReview": "综合健康评价",
   "suggestedMaterials": "建议补充材料",
   "advancedQuestions": "建议进一步了解的问题"，
   "advancedSurveySchema": SurveySchema // 问卷schema 定义见附件
}
```

## 触发报告生成接口\(灵犀提供\)

> 提供方：灵犀
> 
> 

### 入参

```JSON
{
  "userId": "",  // 用户 ID
  "name": "张三",
  "age": 30,
  "gender": "男" | "女",
  "groupId": "", // im 群组 id，用于后续获取聊天记录
  "surveyList": [ // 问卷列表
    {
       "schema": SurveySchema // 问卷schema 定义见附件,
       "answer": {} // 问卷提交答案，结构见附件
    },
    ...
  ],
   **"hospitalData"**: [        //医院检验检查的数据，可能为空

    ],
    //宏基因检测数据  包括原始报告的pdf，和字段解析和模板id，配型报告url
    **"microbiomeReportData"**: {
        **"originalReportUrl"**: **"https://test.slmc.top/api/v1/file/preview?objectName=32eb34c960ef5f003936e7b8f5d5d712.pdf"**,
        **"dataInfoUrl"**: **"https://test.slmc.top/api/v1/file/preview?objectName=f485d6d1b769a18defeb216516fd1ff3.json"**,
        **"templateNumber"**: **"T250627161148",**
        "fmtTypingReportUrl":"https://test.slmc.top/api/v1/file/preview?objectName=aa04465104c1284cf5f592cd71189d5b.pdf"
    }
}
```

### 预期返回

通过回调接口返回 评估报告，报告解读，干预方案，定制服务
